# Dissertation

Code and data for the MSc dissertation investigating the climate-driven distribution, habitat suitability, and spatial niche dynamics of the invasive plant species *Parthenium hysterophorus*.

## Repository Structure

* `code/`: R scripts for Generalized Additive Models (GAMs), MaxEnt projections, spatial concordance analysis, and manuscript figure formatting.
* `data/`: Occurrence data, environmental predictor layers, and spatial covariates.
